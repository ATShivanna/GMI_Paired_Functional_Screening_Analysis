# GitHub / Zenodo Release Notes

## v1.0.1 — Initial public release

This release accompanies the manuscript under revision:

**Paired functional screening reveals GMI-modulated drug response behavior in heterogeneous tumor models**

This version includes:

- Complete Python analysis workflow.
- Scripts for data extraction and viability normalization.
- ΔMin and ΔAUC modulation-response analyses.
- Pathway aggregation and hierarchical clustering workflows.
- Kruskal–Wallis testing and Benjamini–Hochberg FDR correction.
- Figure-generation scripts.
- Regeneration script and output files for Supplementary Figures S9 and S10.
- Repository metadata for GitHub citation and Zenodo archiving.

Representative processed datasets are provided with the accompanying manuscript as Supplementary Data S1 and Supplementary Data S2. Raw screening data are available from the corresponding author upon reasonable request.
